# OpenCode 安装与常用教学

## 安装

1. 下载安装 [Node.js](https://nodejs.org/zh-cn/download)
2. 终端执行：
   ```bash
   npm i -g opencode-ai
   ```
3. `Ctrl+R` 运行 `opencode` 即可启动

## 常用命令

| 命令 | 作用 |
|------|------|
| `/skills` | 调用技能 |
| `/models` | 切换模型 |
| `/sessions` | 选择历史对话 |
| `/compact` | 整理上下文 |
| `Ctrl+T` | 切换思考模式 |

## 开发教学

以开发一个前后端项目为例，完整流程如下：

### 一、写文档和计划

```bash
/skills brainstorming
```

告诉 AI 你想开发什么、用什么语言，**并说明项目存放路径**。让 AI 写出完整的需求文档和开发计划。

### 二、出前端方案

推荐使用 **`frontend`** 命令（自动加载 `frontend-design` + `ui-ux-pro-max` 两个 skill）：

**流程：**

1. 告诉 AI 项目目录，把上一步写的文档和计划给它看
2. AI 自动出 **8-15 个方案** → 生成 HTML 对比页 → 打开浏览器预览
3. 不满意 → 让 AI 重新出一批；满意 → 选第 X 号
4. AI 出详细设计体系 HTML → 自动打开浏览器
5. 确认后 AI 问是否关闭本地端口

> 💡 如果没有文档，先调 brainstorming 写完再回来。

### 三、执行开发

按 `Tab` 切换模式：

| 模式 | 作用 |
|------|------|
| Plan | 只出方案和计划，不修改文件 |
| Build | 直接写代码 |

前端方案确定后，用**子代理**模式执行开发：

1. 先把设计体系（色号、字体、CSS 变量等）发给 AI
2. 使用子代理模式运行开发计划
3. 日常聊天开 **Plan 模式**，遇到 bug 前先用 Plan 给出方案，确认后再用 Build 修改
